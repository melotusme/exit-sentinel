## 已处理

- 排除本地研究、验收、技能记录等历史文档，其中含个人路径、历史出口 IP 和网络配置。

- 更新私钥保存在仓库外；客户端内置的 updater pubkey 是允许公开的验签公钥。

- Shadowrocket 适配层仅输出节点身份 / 路由元数据，不导出密码、密钥或订阅链接。数据只落本机，不进入发布包。
