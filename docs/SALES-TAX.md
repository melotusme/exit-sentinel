# 美国出口销售税提示

“免税州”指无州级一般销售税的州：Alaska (AK)、Delaware (DE)、Montana (MT)、New Hampshire (NH)、Oregon (OR)。阿拉斯加地方政府可能征收地方销售税；其他州也可能有特定产品、地区或交易规则。

使用 ipwho.is 的 country_code / region / region_code 离线判断。州名优先；只有州名缺失才使用州代码。不识别的州份、缺失国家或州份显示未确认，非美国显示不适用。已缓存地理信息会在读取时补上分类，不额外发送查询。

此提示不证明用户实际位置、账单地址或某项订阅 / 交易的税额。具体交易以商户及税务机关规则为准。

参考：[Oregon Department of Revenue](https://www.oregon.gov/dor/programs/businesses/pages/sales-tax.aspx)、[Alaska Tax Division](https://tax.alaska.gov/programs/programs/index.aspx?10000)。
